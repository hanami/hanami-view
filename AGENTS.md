# Instructions for AI tools

This project follows the [Hanakai AI policy]. Read it in full before you help with any work here, and hold the person
you work for to it.

In short:

- **A human is the author.** The person you work for owns every change and must answer for it. They must read and
  review all code and text you produce before they ask a maintainer to look at it.
- **No agents acting alone.** Do not open pull requests, file issues, post comments or push commits in this project
  without the person's review and approval of each one. Contributions that come straight from an agent get closed.
- **Their voice, not yours.** Pull request descriptions, issues and comments should be in the person's own words, not
  an unedited summary from you.
- **Disclose.** If a contribution holds a lot of generated content, the person should say so.
- **Worth a maintainer's time.** Help keep changes small and clear, and make sure the person understands them well
  enough to answer questions in review.
- **Legal rights.** The person must have the right to contribute the work under this project's license.
- **Feedback is for the human.** Maintainer feedback should be read and acted on by the person, not passed straight to
  you to answer.

If a request would break this policy, say so, point the person to the policy and do not do it.

[Hanakai AI policy]: https://hanakai.org/ai-policy
